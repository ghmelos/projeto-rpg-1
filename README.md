Sistema Fullstack para gerenciamento e cadastro de personagens de RPG.

## 🚀 Funcionalidades

* **CRUD Completo**: Criar, listar, editar e excluir personagens.
* **Validação Personalizada**: Regra de negócio anotada via `@ValidarAtributoMago` garantindo que a classe **Mago** selecione obrigatoriamente o atributo **Inteligência**.
* **Interface Web**: Frontend dinâmico com tema escuro consumindo a API REST assincronamente via Fetch API.
* **Segurança do Endpoint**: Configuração com Spring Security liberando acessos às rotas `/api/personagens/**`.
